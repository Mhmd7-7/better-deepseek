# Better DeepSeek — Chrome

نسخة Chrome الجاهزة للتشغيل، مع تحسينات مستقلة للواجهة في الإصدار `0.1.16`.

## الوصول السريع

- زر عائم يفتح قائمة مختصرة دون الحاجة للتنقّل داخل قوائم الإضافة.
- بحث محلي داخل رسائل المحادثة المحمّلة، مع معاينة النص وتحديد الكلمة المطابقة. اختر نتيجة للانتقال إلى الرسالة.
- أزرار لكتابة رسالة، وفتح لوحة BDS، والانتقال لأول رسالة وآخر رسالة.
- واجهة عربية من اليمين لليسار، وواجهة إنجليزية، وعرض مناسب للشاشات الصغيرة والوضع الداكن.
- افتح القائمة باستخدام `Ctrl + Shift + K`، أو `⌘ + Shift + K` على Mac. استخدم الأسهم للتنقّل و`Enter` للاختيار و`Esc` للإغلاق.

لغة القائمة تتبع لغة إعدادات BDS عند تحديدها، وإلا تتبع لغة المتصفح. اللغات الأخرى تعرض القائمة بالإنجليزية.

البحث لا يرسل محتوى المحادثة لأي خادم، ولا يبحث في المحادثات الأخرى أو الرسائل التي لم تُحمّل في الصفحة. في المحادثات الكبيرة، يعرض أول 50 نتيجة مع العدد الإجمالي؛ حدّد عبارة البحث للوصول لنتيجة أدق.

## التثبيت

1. نزّل ملفات المستودع أو الملف المضغوط للإضافة، ثم فك الضغط.
2. افتح صفحة إضافات Chrome وفعّل وضع المطوّر.
3. اختر **Load unpacked / تحميل إضافة غير محزّمة** وحدّد المجلد الذي يحتوي على `manifest.json`.
4. أعد تحميل صفحة DeepSeek. إذا كانت نسخة سابقة مثبتة، أعد تحميل الإضافة من صفحة الإضافات أولًا.

تصميم القائمة يدعم الشاشات الصغيرة، لكن تثبيت الإضافة على الهاتف يحتاج متصفحًا يدعم إضافات Chrome؛ متصفح Chrome العادي على Android لا يدعمها.

## التطوير والاختبار

ملفات الإضافة الأساسية هي ملفات النسخة المجمّعة المرفوعة للمستودع. التحسينات الجديدة في `enhancements/quick-access.js` و`enhancements/quick-access.css`، ويحمّلها `manifest.json` مباشرة؛ لا تحتاج إلى خطوة بناء أو مكتبات إضافية وقت التشغيل.

لتشغيل اختبارات الواجهة، استخدم Node.js حديثًا:

```sh
npm ci
npx playwright install chromium
npm test
```

يمكن استخدام Chromium مثبت مسبقًا عبر متغير `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` الذي يحتوي على المسار الكامل لملفه التنفيذي.

الاختبارات تشغّل القائمة في متصفح فعلي أمام صفحة محادثة تجريبية، مع محاكاة واجهة تخزين Chrome. تتحقق من البحث بالعربية والإنجليزية، والتنقّل، وتحديث الرسائل، وأمان عرض النصوص، وإمكانية استخدام لوحة المفاتيح، وعرض الجوال. لا تتطلب حساب DeepSeek، ولا تختبر الاتصال بالخدمة الفعلية أو وظائف الإضافة القديمة بالكامل.
