# Better DeepSeek — Chrome

إضافة متصفح Manifest V3 مع مساحة لتنفيذ المهام في الإصدار التجريبي `0.2.0`. تعمل داخل موقع DeepSeek بحسابك الحالي، دون خادم أو تطبيق مستقل أو اشتراك API إضافي.

## مساحة المهام

افتح **مساحة المهام** من الزر العائم، واكتب نتيجة محددة، ثم اضغط **ابدأ المهمة**. تُرسل تعليمات المهمة إلى محادثتك الحالية، وتعرض اللوحة الخطوات والملفات وسجل التنفيذ. يواصل المساعد العمل حتى يعلن اكتمال المهمة أو يظهر عائق أو تضغط **إيقاف المهمة**.

- البحث وقراءة صفحات الويب مع روابط المصادر، وتحويل النتائج إلى تقرير.
- استيراد TXT وMD وCSV وJSON وXLSX. الملفات محلية وغير مشاركة افتراضيًا؛ اختر مربع **مشاركة مع المهمة** للسماح بقراءتها وإرسال نتائجها إلى DeepSeek.
- تحليل البيانات باستخدام JavaScript معزول ومكتبة XLSX، بما يشمل الملف المختار كاملًا، وإنشاء ملفات DOCX وXLSX وPPTX.
- إنشاء ملفات مشاريع بأسماء ومسارات نسبية، وتنزيل النتائج منفردة أو في ZIP، دون الكتابة المباشرة على مجلدات جهازك.
- متابعة الخطوات، وإعادة المحاولة الصريحة، وطلب إصلاح من DeepSeek. لأخطاء الكود والمستندات محاولة إصلاح تلقائي واحدة؛ لا توجد حلقة إعادة غير محدودة.
- سجل مهام داخل المحادثة للرجوع إلى نتائج المهام السابقة وملفاتها. أوقف المهمة النشطة أو أكملها قبل فتح مهمة أخرى في التبويب نفسه.

المهام مرتبطة بالمحادثة والتبويب. تغيير المحادثة أو كتابة رسالة يدويًا يوقف المتابعة التلقائية مؤقتًا. بعد إعادة تحميل الصفحة، يلزم الاستئناف الصريح. إذا أُغلق تبويب المهمة، يمكن استعادتها في تبويب آخر لنفس المحادثة.

**حدود التنفيذ:** 30 استدعاء أداة قبل طلب المتابعة، و30 ثانية لتشغيل الكود، و20MB للملف و100MB لملفات المهمة. معاينات النصوص والجداول محدودة وتُوسم كذلك؛ التنزيل يحافظ على الملف كاملًا. عند تحليل CSV/XLSX، يستطيع المساعد طلب كامل الملف الذي اخترته، وليس المعاينة وحدها.

الكود المعزول لا يصل إلى DOM أو التخزين أو الشبكة أو أوامر النظام. Python اليدوي الموجود سابقًا باقٍ؛ التنفيذ التلقائي الجديد يدعم JavaScript. أدوات MCP اختيارية، وتحتاج خادمًا أعددته مسبقًا وموافقتك على كل إجراء خارجي. إلغاء إجراء خارجي بدأ بالفعل لا يثبت أن الخادم تراجع عنه؛ تعرض اللوحة نتيجة غير معروفة عند تعذّر التأكد.

تُحفظ بيانات المهام والملفات محليًا في IndexedDB داخل الإضافة، وتظل موجودة بين مرات فتح المتصفح حتى تزيل الملفات. سجل التنفيذ المعروض يحتوي على أسماء الأدوات والحالات والمدد دون المدخلات ومحتوى الملفات. البحث يرسل عبارة البحث إلى مزوّده، وقراءة الروابط تتصل بالمواقع المطلوبة؛ لا تتجاوز الإضافة قيود تسجيل الدخول أو اختبارات التحقق في تلك المواقع.

## الوصول السريع

- زر عائم يفتح قائمة مختصرة دون الحاجة للتنقّل داخل قوائم الإضافة.
- بحث محلي داخل رسائل المحادثة المحمّلة، مع معاينة النص وتحديد الكلمة المطابقة. اختر نتيجة للانتقال إلى الرسالة.
- أزرار لكتابة رسالة، وفتح لوحة BDS، والانتقال لأول رسالة وآخر رسالة.
- تبويبان للرسائل وملفات الأكواد، يحتفظ كل منهما بعبارة بحث مستقلة أثناء فتح القائمة.
- واجهة عربية من اليمين لليسار، وواجهة إنجليزية، وعرض مناسب للشاشات الصغيرة والوضع الداكن.
- افتح القائمة باستخدام `Ctrl + Shift + K`، أو `⌘ + Shift + K` على Mac. استخدم الأسهم للتنقّل و`Enter` للاختيار و`Esc` للإغلاق.

لغة القائمة تتبع لغة إعدادات BDS عند تحديدها، وإلا تتبع لغة المتصفح. اللغات الأخرى تعرض القائمة بالإنجليزية.

البحث لا يرسل محتوى المحادثة لأي خادم، ولا يبحث في المحادثات الأخرى أو الرسائل التي لم تُحمّل في الصفحة. في المحادثات الكبيرة، يعرض أول 50 نتيجة مع العدد الإجمالي؛ حدّد عبارة البحث للوصول لنتيجة أدق.

## المحادثات والملفات

- احفظ نصوص الرسائل المحمّلة كملف Markdown أو JSON. إذا كتبت عبارة بحث، يحتوي التصدير على **كل الرسائل المطابقة** حتى لو تجاوز عددها 50، وليس النتائج المعروضة فقط.
- يجمع تبويب **ملفات الأكواد** مقاطع الكود من المحادثة. ابحث باسم الملف أو اللغة أو محتواه، ثم انسخ الكود أو نزّله مع الحفاظ على المسافات والأسطر والعربية.
- معاينة الكود محدودة الطول لتخفيف الواجهة؛ النسخ والتنزيل يستخدمان النص الكامل. تظهر رسالة توضيحية إذا تعذّر النسخ.

هذه الأدوات لا تنفّذ الأكواد. تبويب الملفات يختص بمقاطع الكود المحمّلة، ولا يجلب المرفقات الثنائية أو الملفات من محادثات أخرى. التصدير يحفظ نص الرسائل، وليس نسخة مطابقة لتنسيق صفحة DeepSeek أو مرفقاتها.

بحث الوصول السريع يعيد استخدام فهرس في الذاكرة أثناء فتح قائمته ويحدّث الرسائل المتغيّرة فقط. يُمسح هذا الفهرس عند إغلاق القائمة. تخزين مساحة المهام مستقل عنه كما هو موضح أعلاه.

## التثبيت

1. نزّل ملفات المستودع أو الملف المضغوط للإضافة، ثم فك الضغط.
2. افتح صفحة إضافات Chrome وفعّل وضع المطوّر.
3. اختر **Load unpacked / تحميل إضافة غير محزّمة** وحدّد المجلد الذي يحتوي على `manifest.json`.
4. أعد تحميل صفحة DeepSeek. إذا كانت نسخة سابقة مثبتة، أعد تحميل الإضافة من صفحة الإضافات أولًا.

تصميم القائمة يدعم الشاشات الصغيرة، لكن تثبيت الإضافة على الهاتف يحتاج متصفحًا يدعم إضافات Chrome؛ متصفح Chrome العادي على Android لا يدعمها.

## التطوير والاختبار

المصدر القابل للتطوير في `src/`، وأدوات الوصول السريع في `enhancements/`. استُعيد أساس المصدر من `704bcfe` مع تحديثات نسخة `0.1.15` حتى `490db8c`، للمحافظة على الميزات الموجودة في الملف المضغوط، ومنها MIDI والتصدير الموسّع. لا يتضمن مسار البناء تطبيق Android أو مشغّلًا خارجيًا.

لتطوير الإضافة وتشغيل الاختبارات، استخدم Node.js 24 كما هو محدد في `.nvmrc`:

```sh
npm ci
npm run build
npx playwright install chromium
npm test
```

يمكن استخدام Chromium مثبت مسبقًا عبر متغير `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` الذي يحتوي على المسار الكامل لملفه التنفيذي.

- `npm run build`: يبني `dist-chrome/` ويحدّث ملفات التشغيل في جذر المستودع؛ الجذر يبقى صالحًا للتحميل كإضافة غير محزّمة.
- `npm run dev`: يراقب المصدر والملفات الثابتة ويعيد البناء. أعد تحميل الإضافة وصفحة DeepSeek بعد التغيير.
- `npm run test:unit`: اختبارات المصدر ومحرك المهام والتكامل مع الأدوات.
- `npm run test:ui`: اختبارات Chromium للواجهة والعامل المعزول والحزمة المجمّعة، مع محاكاة Chrome وصفحة DeepSeek.
- `CI=1 npm run test:extension`: اختبار تحميل `dist-chrome/` كإضافة حقيقية أمام صفحة تجريبية، باستخدام Chromium المخصص للاختبار. هذا فحص مستقل عن `npm test`.

لتجهيز ملف ZIP يحتوي على ملفات التشغيل فقط، مع التحقق من سلامتها، يلزم Python 3:

```sh
npm run package:extension
```

يُحفظ الملف في مجلد `artifacts/`؛ لا يتضمن أدوات التطوير أو ملفات الاختبار.

ملف التثبيت يحتوي ملفات التشغيل فقط. مكتبات Office والعامل الجديد مضمنة محليًا، ولا تحتاج تثبيت npm عند استخدام ملف ZIP.

## حالة المعاينة

اختبارات الواجهة تستخدم متصفحًا فعليًا وصفحة محادثة وخدمات تجريبية. تختبر أيضًا الحزمة المجمّعة ومسار إرسال الأدوات وجلب المصادر وإنشاء ملف Word. هذه الاختبارات لا تثبت أن نموذج DeepSeek سيتبع كل مهمة أو أن محددات الموقع ستظل ثابتة بعد تحديثه.

المتصفح المثبّت في بيئة التطوير يمنع تحميل الإضافات غير المحزّمة، وتنزيل متصفح الاختبار مرفوض بسياسة الشبكة. لذلك اختبار الإضافة الحقيقي واختبار حساب DeepSeek المسجّل الدخول واختبار جهاز Android فعلي لم تُجتز بعد. تفاصيل التحقق والخطوات المتبقية في [دليل التحقق](docs/VALIDATION.md). لا يُعد هذا إصدارًا مستقرًا قبل اجتياز هذه الفحوص.
