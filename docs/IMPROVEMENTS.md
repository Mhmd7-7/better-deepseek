# تحسينات Better DeepSeek — 4 نوفمبر 2026

## ما تم تنفيذه

### قراءة Live عبر زر DeepSeek الأصلي

- لم يعد Live يولّد صوتًا بنفسه: عند اكتمال رد الدور الحالي يُضغط زر **Read aloud** الأصلي داخل صف الرد نفسه، بنفس صوت DeepSeek وطريقة تشغيله اليدوية. لا WebSocket خاص، ولا تذكرة، ولا PCM، ولا صوت متصفح أو نظام أو خدمة خارجية.
- تحقّق الاكتمال لا يعتمد على سكون النص: جسر المرتبط بطلب التوليد يشترط نجاح HTTP وإغلاق النقل، ثم يشترط ظهور زر القراءة الأصلي متاحًا في الصف المرتبط. علامة `[DONE]` تُوسم صريحة، وإغلاق نظيف يُوسم نقلًا، وإن لم يصل الجسر فالزر الأصلي المستقر بعد بدء الطلب يكمل الشرط. أي غموض يفشل بأمان ويظهر سببًا مرئيًا.
- هوية الرد لا تعتمد على النص أو الترتيب أو `data-bds-msg-id` العشوائي: يُرصد الصف المساعد الجديد الفريد نسبةً إلى ما قبل الإرسال ويُربط بمفتاح الصف `data-virtual-list-item-key`، مع دعم إعادة الإدراج الافتراضي وإعادة التوليد كإصدار جديد، وتبنّي جلسة الطلب في محادثة جديدة بلا `/chat/s/`.
- الزر يُبحث عنه داخل شريط أدوات الصف المرتبط فقط (قد يكون شقيقًا للمحتوى)، ويُفعّل مرة واحدة. لا يُقرأ أي رد قديم عند بدء Live أو تحميل الصفحة أو التمرير.
- الميكروفون يتوقف قبل التفعيل. يرصد سياق الصفحة تشغيل/انتهاء صوت الموقع نفسه (`<audio>/<video>` أو Web Audio) بعد التفعيل، فيخرج Live من «Speaking…» ويعود للاستماع تلقائيًا عند انتهاء الرد. إن تعذّر رصد المشغّل يظهر زر **استئناف الاستماع** في رأس Live بدل تخمين انتهاء الصوت.
- دورة التشغيل: لا يُفترض أن الضغط مرة أخرى يوقف الصوت. إذا كان عنصر الوسائط الأصلي مرئيًا تُرصد بداياته ونهاياته؛ وإلا تظهر أزرار **تشغيل الرد / السماح بالصوت** و**إيقاف الرد** و**أوقف الصوت — استئناف الاستماع** بدل تخمين التوقيت.
- أي ضغط يدوي ثانٍ أثناء صوت Live يُعتبر حالة غامضة ويُبقي الميكروفون معلقًا حتى تأكيد المستخدم؛ تغيير المحادثة أو إيقاف Live أو إغلاق الصفحة ينظّف المراقبات والطلبات المعلقة.
- تُرصد رسائل DeepSeek الأصلية أثناء الطلب («Read aloud isn’t supported for this language yet»، الحصة، حدّ المعدل): يُحرّر الميكروفون فورًا، ويظهر سبب واضح، ولا تُعاد محاولة اللغة غير المدعومة في الجلسة نفسها. لا صوت بديل.

### الوصول السريع والبحث

- البحث في الرسائل يدعم أكثر من كلمة، ويتجاهل اختلافات الألف والتشكيل والتطويل العربي، وكذلك accents اللاتينية.
- النص الأصلي محفوظ في العرض والتصدير. التظليل يعود إلى محارف النص الأصلي ولا يستخدم HTML من المحادثة.
- فلترة النتائج: الكل / أنت / المساعد مع أعداد مطابقة لكل نوع، وزر مسح البحث.
- حفظ الرسائل يطبّق البحث والفلتر، ويشمل كل النتائج المطابقة وليس أول 50 المعروضة فقط.
- البحث في ملفات الأكواد بقي بحثًا نصيًا حرفيًا غير حساس لحالة الأحرف؛ لا يوجد تغيير في الكود المنسوخ أو المحمّل.
- وصول مباشر إلى إعدادات الصوت قبل فتح Live أو طلب الميكروفون.
- انتقال التركيز بين نافذتي الوصول السريع والصوت تم التحقق منه في Chromium، ودعم IME ولوحة المفاتيح محفوظ.

### إزالة الصوت المحلي ولوحة الصوت الجديدة

- حُذف محرك Piper كاملًا: `local-tts/` (خادم Python والنماذج وسكربتات التثبيت)، و`enhancements/local-tts.js` و`local-tts.css` و`local-tts-background.js`، واختبارات الخدمة والكتالوج.
- لم يبقَ أي طلب شبكة إلى `127.0.0.1:17863`، ولا صلاحية منفذ، ولا تثبيت Python أو تنزيل نماذج. لا توجد خدمة تحتاج تشغيلًا بجانب المتصفح.
- لوحة الصوت `voice-panel.js` صارت لغتين فقط: **لغة استماع Live** (71 خيارًا مع رمز BCP 47 مخصّص) و**مفتاح القراءة الأصلية في Live**، مع **فحص زر القراءة الأصلي — بدون تشغيل**. لا اختيار صوت متصفح ولا سرعة ولا تجربة صوت.
- اللغة تُحفظ في `bds_settings` ويستخدمها محرك Live للتعرف؛ تغييرها أثناء Live يعيد تشغيل التعرف ويصفّر النص الجزئي.

## طريقة التفعيل

1. أعد تحميل Better DeepSeek من `chrome://extensions` أو `edge://extensions`، ثم حدّث صفحة DeepSeek.
2. من الوصول السريع أو `Ctrl+Shift+K` افتح **إعدادات الصوت**، وتأكد من **قراءة الردود بصوت DeepSeek في Live** (مفعّلة افتراضيًا للملف الجديد)، واختر **لغة استماع Live**.
3. داخل Live تحدّث مرة واحدة وانتظر اكتمال الرد؛ سيُضغط زر الموقع الأصلي مرة واحدة. للتحقق دون تشغيل استخدم **فحص زر القراءة الأصلي — بدون تشغيل**.
4. للإيقاف استخدم كتم/إيقاف Live أو **إيقاف الرد**. إذا طلب منك التأكيد فأوقف الصوت من DeepSeek ثم اضغط **أوقف الصوت — استئناف الاستماع**.

## حدود العمل

- لا يوجد تغيير لمسارات أو برامج Java؛ رسائل المستخدم العرضية تم تجاهلها كما طلب.
- البحث يشمل الرسائل المحمّلة في الصفحة فقط. لا نطلب تاريخ محادثات إضافيًا من الشبكة.
- النطق كله عبر DeepSeek: لا صوت محلي ولا صوت متصفح. التعرّف على كلام المستخدم ما زال عبر المتصفح وقد يحتاج الإنترنت.
- لا WebSocket خاص ولا تذكرة ولا PCM: النقر يفعّل زر الموقع الأصلي فقط. قد يكون الصوت غير قابل للرصد (Web Audio)؛ حينها يبقى الميكروفون معلقًا حتى يؤكد المستخدم توقف الصوت.
- لم يتوفر ملف HTML المرفق في مساحة العمل أو مرفقات DSH، ولم يكن للمتصفح منفذ فحص؛ لذلك بنية شريط الأدوات ودلالة مفتاح الصف وإشارات الوسائط الأصلية لم تُتحقق وقت التشغيل، والتنفيذ يفشل بأمان عند الغموض.
- لم تُختبر جلسة ميكروفون من حساب المستخدم داخل DeepSeek، ولا تُقاس جودة الصوت بالسماع. اختبار Chromium الحقيقي يستخدم DOM/وسائط اصطناعية (19/19) ولا يشغّل حسابًا أو صوتًا.
- لا توجد خدمة بدء تشغيل Windows أو تعديل إعدادات نظام مخفي.
- لا يوجد prefetch متعدد أو إعادة كتابة لمحرك الصوت؛ التحسين هنا يركز على الثبات، الوصول، والتشخيص الصادق.
